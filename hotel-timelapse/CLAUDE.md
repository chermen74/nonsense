# Hotel Timelapse — project instructions for Claude Code

Read `BUILD_SPEC.md` (revenue side, §0–§9) and `SPEND_SPEC.md` (cost side, §10–§16) before writing code. They are the source of truth; if code and spec disagree, fix the code or propose a spec edit — never silently diverge.

## What this is
A client-side 3D replay of one month of hotel operations: rooms light and dim, guests and staff visibly move, outlets and function rooms fill and empty, and department revenue/cost/profit tallies accrue on a scrubbable variable-speed clock. It is a standalone product that deploys to any hotel unchanged; all property specifics come from config and data files.

## Hard rules
- Never hard-code a property name, room number, outlet, department, vendor, or system name in `src/`. Everything comes from `public/property.json`, `public/layout.json`, and `public/data/YYYY-MM.json`.
- Never commit real property data. `public/data/2026-08.json` is synthetic (generated by `prep/gen_synthetic_month.py`) and is the only data file in the repo.
- No network calls from the app. It must run from `vite build` output on any static host or intranet folder.
- All scene state is a pure function of sim time `t`. No mutation-on-tick. Scrubbing backwards must be free.
- Use `InstancedMesh` for rooms, guests and staff. Never a React component per entity.
- Every tally on screen comes from `accruedThrough(t)`; at `period_end` it must equal the file totals to the cent. Keep the load-time reconciliation log.

## Stack
Vite + React 18, `three` + `@react-three/fiber` + `@react-three/drei`, `zustand`. Python 3.11 for `prep/`. No other runtime dependencies without asking.

## Layout
```
public/property.json        property identity + brand (demo: property.demo.json)
public/layout.json          geometry: wings, rooms, outlets, function rooms, departments
public/data/YYYY-MM.json    month data in the §3 + §11 schema
prep/gen_synthetic_month.py synthetic month generator
prep/adapters/              one file per source system (phase 2/3)
prep/reconcile.py           file totals vs any GL CSV
src/sim/accrue.ts           accruedThrough(t) + keyframe precompute
src/sim/segments.ts         movement segment builder (guests, staff, deliveries)
src/scene/                  r3f components: Building, Rooms, Guests, Staff, Zones, Camera
src/ui/                     Transport, Clock, TallyPanel, Waterfall, DeptZoom
```

## Working style
- Follow the build order in BUILD_SPEC §9 then SPEND_SPEC §16. Finish and verify a step before starting the next.
- After each step, run `npm run dev`, load August, and confirm the acceptance line for that step. Report what was verified, not what was written.
- Prefer small commits with the step number in the message (`step 3: sim clock + tally panel`).
- If a spec rule is ambiguous, state the interpretation you chose in the commit message and move on; do not stall.
